# Device and browser checklist (Week 5)

A short manual pass on real devices, because automated tests cannot install the app or tap a
phone screen. Run it after deploying, with one everyday account and the admin account.
Tick each box per browser; note anything odd next to it.

Browsers: **iPhone Safari**, **Android Chrome**, **desktop Chrome**, **desktop Firefox**,
**desktop Edge**.

## Install as an app

- [ ] iPhone Safari: Share → *Add to Home Screen*. The icon is the Muninn raven, the name under
      it is "Muninn", and it opens full screen with a dark status bar.
- [ ] Android Chrome: menu → *Install app* (or *Add to Home screen*). Same icon and name; opens
      without the address bar.
- [ ] Desktop Chrome/Edge: the install icon appears in the address bar and the installed app opens
      in its own window.
- [ ] The installed app still asks you to sign in after you sign out (nothing works offline, by design).

## Everyday account

- [ ] Sign in, see the notes page. The top bar fits on one line.
- [ ] Create a note with a checklist, a code block, a link and a pasted or picked image.
- [ ] Tick a checklist box in the read view.
- [ ] Edit the note twice, open History, restore the older version.
- [ ] Search finds the note; archive it, find it with "Include archived notes".
- [ ] Delete it, restore it from Trash.
- [ ] Shared workspace: create one, add a second user as Editor, confirm they see the note.
- [ ] Account page: change your password, sign in again with the new one.
- [ ] Account page: ask for someone to be invited.

## Admin account

- [ ] Invitations: the request shows; approve it.
- [ ] Back as the everyday user: *Create link*, copy it, open it in a private window, create the account.
- [ ] Users: *Reset password* for a test user; open the link in a private window, set a new
      password, sign in with it.
- [ ] Workspaces: open *Members* of a shared workspace; change a role and change it back.

## Keyboard and screen reader (desktop, one browser is enough)

- [ ] Tab from the top: the "Skip to main content" link appears first, then every control is
      reachable and shows a gold focus ring.
- [ ] The current page's link in the top bar is underlined.
- [ ] With VoiceOver (iPhone) or TalkBack (Android): icon-only buttons in the top bar are read
      out by name (Search, Workspaces, Your account, Sign out).
